XBPS Repo on USB Drive

As a Void Linux user, I always felt the need for a local package repository that lets me install the packages I want at any time and on any device without delays and without needing a continuous internet connection. For this reason, I turned one of my USB drives into a portable local XBPS repository.

Why Local Repo

There were several reasons that drove me to create a local repository, most notably:-

1- Slow Internet
My download speed often hovered between 180 and 200 KB/s, making the process of downloading packages (even small ones) take a very long time.
2- Repeated Downloads
Due to my passion for tinkering and technical experiments, I frequently reinstalled the OS on multiple devices, I found myself downloading the same packages over and over again, which wasted time, consumed bandwidth, and slowed down my learning process.
3- My Country's Internet Service
Constant price hikes for internet packages, data capping policies, frequent outages (such as government-enforced internet blackouts during exam seasons), and the blocking of important websites (like archive.org), all of these factors made me lose trust in the internet in my country. This pushed me to strive for self-reliance and host everything I need locally.

Why USB Drive

Initially, the plan was to turn my old HP laptop into a home server to host various services, including an XBPS repository. But due to some hardware and battery issues, I postponed the server project for now and started with something simpler. That is why I chose a USB Drive as a quick and simple temporary solution.

What I Did

This is not a tutorial, it is just a walkthrough of the steps I took.

I used an 8GB SanDisk Cruzer Blade USB drive and created a single 8GB partition with the ext4 filesystem, since I will be using it only with Linux devices. After inserting it into my laptop, I identified its name using lsblk and mounted it to a specific directory, let's say (/home/USER/myrepo).

Now, I can download the packages I need using xbps-install

xbps-install -D -c /home/USER/myrepo PKGNAME

Next, I create the repository index using xbps-rindex

xbps-rindex -a /home/USER/myrepo/*.xbps

At this point, I can search for packages inside the repository using xbps-query. For example, to list all packages in the repository

xbps-query -Ris --repository /home/USER/myrepo ""

After that, I can install any package I want using xbps-install

This process requires root permissions.
xbps-install -i -c /home/USER/myrepo -R /home/USER/myrepo PKGNAME

When I want to update the packages in the repository. I download the newer version using xbps-install (like the first step) and add it to the index using xbps-rindex (like the second step). At this point, xbps-rindex takes care of adding the new packages and removing the index entries for the old ones. But the old package files will still exist in the repository folder (USB drive), they can be removed up using xbps-rindex

xbps-rindex -r /home/username/myrepo/

Once finished, I can unmount the USB drive using umount and unplug it.

What is Next

I know this method is simple and it is not the best way to create a repository, but it is just a temporary solution for learning. The next step (after fixing my old laptop) will be to create a local server that hosts multiple services, and one of them will be an XBPS repository.
